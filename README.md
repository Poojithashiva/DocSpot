# 🏥 DocSpot – Healthcare Appointment Booking System

## 📌 Overview
DocSpot is a full-stack web application that allows patients to book doctor appointments online with role-based access for patients, doctors, and admins.

## 🚀 Features
- User registration and login authentication
- Doctor browsing and filtering
- Appointment booking system
- Admin approval dashboard
- Real-time appointment scheduling

## 🛠 Tech Stack
Frontend: React.js, Bootstrap, Axios  
Backend: Node.js, Express.js  
Database: MongoDB  

## ▶ How to Run Locally

### Backend
cd backend
npm install
node server.js

### Frontend
cd frontend
npm install
npm start
